常见问题

支持哪些操作系统？

支持 Windows 7 / 8.1 / 10 / 11（32/64 位均可）。需要 .NET Framework 4.x，绝大多数系统已自带，无需额外安装。

古月工具包收费吗？

完全免费开源、无激活、无功能限制，也没有广告或捆绑，可以放心使用。

优化会不会把系统搞坏？

不会。每一项优化在执行前都会自动备份原注册表 / 服务值，关掉开关即完整还原；高危项还会二次确认并自动创建系统还原点，新手也能放心使用。

它会收集我的隐私数据吗？

不会。古月工具包在本地运行，不做任何数据上传或用户追踪；「隐私清理」反而是帮你清除本机使用痕迹。

怎么更新到新版本？

软件启动时会自动检查最新版本（也可在「关于与更新」手动检查），发现新版本可一键下载安装，安装包会经过 SHA256 校验防止被篡改。

为什么需要管理员权限？

部分系统级操作（改注册表、管服务、磁盘维护等）需要管理员权限。非管理员运行时会给出提示，多数只读功能仍可正常使用。
