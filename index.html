这是一个什么工具

古月工具包（GuyueBox）是一个用 C# / WinForms 编写的 Windows 桌面工具集，采用深色界面。它把日常会用到的系统优化、垃圾清理、系统配置和网络维护集中在一个程序里，不需要安装——下载后以管理员身份双击即可运行。

工具对注册表、服务的每一项修改，都会在执行前备份原值，关掉对应的开关就能还原；涉及风险的操作会先二次确认，需要时自动创建系统还原点。程序在本地运行，不联网上传数据。

  • 单文件免安装：绿色运行，不写系统目录，可直接删除。
  • 改动可还原：优化项逐项开关，改动前自动备份原值。
  • 免费开源：MIT 协议，无广告、无捆绑、无功能限制。
  • 内置更新：软件内检查新版本，安装包经 SHA256 校验。

常见问题

支持哪些操作系统？

支持 Windows 7 / 8.1 / 10 / 11，32 位与 64 位均可。需要 .NET Framework 4.x，绝大多数系统已自带，无需额外安装。

需要付费或激活吗？

不需要。软件以 MIT 协议开源，完全免费，没有激活步骤，也没有广告、捆绑或功能限制。

优化会不会把系统改坏？

不会。每一项优化在执行前都会备份原注册表或服务值，关掉开关即可还原；涉及风险的操作会二次确认，需要时自动创建系统还原点。此外「系统配置」中还提供还原点管理，可以手动创建还原点。

软件会收集我的数据吗？

不会。程序完全在本地运行，不联网上传数据、不做用户追踪。「隐私清理」的作用恰恰是清除本机的使用痕迹。

为什么需要管理员权限？

修改注册表、管理服务、计划任务、磁盘维护等系统级操作需要管理员权限。以普通权限运行时，程序会提示，多数只读功能仍可正常使用。

怎么更新到新版本？

软件启动时会自动检查最新版本，也可以在「关于与更新」里手动检查。发现新版本后可一键下载安装，安装包会经过 SHA256 校验。

卸载后会不会有残留？

程序是单文件绿色版，不写入系统目录，直接删除 exe 即可。它自身的配置保存在用户目录下，删除该配置目录即可完全清除。
