常见问题

支持哪些操作系统？

仅支持 Windows 10 / 11（x64）。需要 .NET Framework 4.8，绝大多数系统已自带，无需额外安装。

古月工具箱收费吗？

基础功能永久免费，可以满足日常加速、清理与优化需求；部分高级能力可能提供可选激活，但绝不强制、无广告。

优化会不会把系统搞坏？

不会。每一项优化在执行前都会自动创建系统还原点并备份原注册表/服务值，可一键完整还原，新手也能放心使用。

它会收集我的隐私数据吗？

不会。古月工具箱在本地运行，不做任何数据上传或用户追踪；「隐私清理」反而是帮你清除本机使用痕迹。

怎么更新到新版本？

软件内置在线更新：启动时会自动检查 GitHub 上的最新版本，发现新版本可一键下载安装，无需手动操作。
